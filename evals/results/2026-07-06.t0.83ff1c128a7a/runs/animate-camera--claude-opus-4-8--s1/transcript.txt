L1597: 
L1598: Type definitions are in `/tmp/noodles-evals/workspaces/animate-camera--claude-opus-4-8--s1/noodles-editor/src/timeline/types.ts` (interfaces `TimelineData`, `TimelineSequenceData`, `TimelineTrackData`, `TimelineKeyframe`). L1599: 
L1600: - **`sheetsById.Noodles`** — the single sheet. Always keyed literally `"Noodles"`.
L1601: - **`staticOverrides.byObject`** — non-animated overridden static values, keyed by object. In practice always written as `{}` (see `toTimelineJSON` line 860). You can leave it `{}`.
L1602: - **`sequence`** — the animation container:
L1603:   - `length` — total duration in **seconds**.
L1604:   - `subUnitsPerUnit` — fps (default 30). Maps to `SequenceState.fps`.
L1605:   - `type` — `"PositionalSequence"` (legacy tag, not required by reader).
L1606:   - `inPoint` / `outPoint` — optional render range in seconds.
L1607:   - `markers` — optional time markers array (omit or `[]`).
L1608:   - **`tracksByObject`** — keyed by **object name** (operator path minus leading `/`; nested containers become `container / nested`). Each object has:
L1609:     - **`trackData`** — map of arbitrary track-id → track. Each track has `type` (`"BasicKeyframedTrack"`), optional `__debugName`, and `keyframes[]`.
L1610:     - **`trackIdByPropPath`** — maps the **property path** to the track-id key used in `trackData`. This is the authoritative link.
L1611: - **Keyframe fields** (`TimelineKeyframe`):
L1612:   - `id` — unique string.
L1613:   - `position` — time in **seconds** (not frames).
L1614:   - `value` — the value at that keyframe (a plain number for viewState channels).
L1615:   - `handles` — `[leftX, leftY, rightX, rightY]` bezier control offsets in normalized 0–1 space. `[0.5, 1, 0.5, 0]` is the standard smooth ease used throughout the example.
L1616:   - `connectedRight` — boolean. `true` = interpolate (bezier) to the next keyframe; `false` = the last keyframe of the track (or a hold). The reader maps `connectedRight ? 'bezier' : 'hold'` (timeline-store.ts line 186), so **set the final keyframe of each track to `false` and all others to `true`**.
L1617:   - `type` — `"bezier"` (written by the store; reader ignores it and derives interpolation from `connectedRight`).
L1618: 
L1619: **Interpolation/easing:** stored per-keyframe via `handles` + `connectedRight`. Native interpolation types are `bezier | linear | hold`; on serialization only bezier/hold are distinguished (linear tracks get written as bezier with linear-ish handles). For a hold (step) transition set `connectedRight: false`.

L1622: 
L1623: `MaplibreBasemapOp` (defined at `operators.ts:3722`) declares `viewState` as a `CompoundPropsField` with number sub-fields `latitude, longitude, zoom, pitch, bearing`.

The reader accepts both, so for hand-authoring use the JSON-array string form as in cesium-hubble — it is the safest and matches what `getFieldFromTrackPath` re-binds against.
