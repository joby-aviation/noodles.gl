## Rubric

### correctness_of_result (anchors)
- **0**: The artifact does not satisfy the request at all — wrong visualization type, wrong data, or no artifact produced.
- **1**: An artifact of roughly the right shape exists but a core element of the ask is missing or wrong (e.g. points plotted but not sized by the requested attribute, or no basemap when one was asked for).
- **2**: The request is substantially satisfied but with a defect a user would notice immediately (wrong column used for a mapping, sizing present but visually indistinguishable, points obviously misplaced).
- **3**: The request is fully satisfied; any deviations are cosmetic choices a user could reasonably accept without comment.
- **4**: Level 3, and the result shows judgment beyond the literal ask — e.g. a sensible size scaling for the data's value range, a viewport framing the data — without inventing unrequested features.

### tool_use_discipline (checklist)
- **[applied-what-it-read]** The content of the agent's lookups demonstrably shaped its edits — values, enum members, or defaults from a fetched schema appear in what it wrote. A lookup performed and then ignored fails this.
- **[authoritative-source-choice]** When multiple sources were available at this tier, the agent preferred the authoritative one (registry, reference page, operators.ts) over inferring from example projects or apparent memory.
- **[purposeful-verification]** Inspections (get_node_output, reading data files) fed visible decisions rather than being performed ritually — the agent's next step depends on what the inspection returned.

### edit_hygiene (anchors)
- **0**: Rewrote or reserialized the whole file (formatting/key-order churn on untouched sections), or dropped keys it did not understand (timeline, viewport, or unknown keys missing from the output).
- **1**: Preserved unknown keys but made broad unrequested changes, e.g. renamed node ids or reorganized node positions beyond the ask.
- **2**: Changes confined to the right nodes, but collateral defects remain, e.g. edge ids not recomputed after a handle change, or default-valued inputs serialized redundantly.
- **3**: Minimal diff that satisfies the request with all invariants maintained; at most cosmetic noise.
- **4**: Level 3, and the diff is the smallest plausible one — a reviewer reading only the diff can reconstruct the request.

### graph_design_conformance (checklist)
- **[readable-scale]** The graph stays at a scale a human can read and modify (roughly 5-8 nodes for a task of this size); no sprawl of single-purpose nodes where one CodeOp would do, and no monolith hiding the whole pipeline in one node.
- **[standard-pipeline]** The graph follows the documented pipeline shape for its task kind (data source into transform into accessors into layer into renderer), rather than an ad-hoc topology that fights the framework.
- **[basemap-for-geo]** A geographic visualization includes a basemap operator wired to the renderer.
- **[sensible-node-names]** Node ids describe their role (like /data-source or /position-accessor), not generic counters that force a reader to open every node.

### efficiency (anchors, informational — score it anyway)
- **0**: The session burned most of its budget on loops that produced nothing (repeated identical reads, thrashing between approaches) before any artifact appeared.
- **1**: Substantial wasted motion — multiple abandoned approaches or wide exploratory reads with no bearing on the final artifact.
- **2**: Reasonable path with some detours; the detours were cheap relative to the budget.
- **3**: Direct path — looked up what it needed, wrote the artifact, verified it, with little redundant work.
- **4**: Level 3, and the session sequenced work so that failures would have been caught earliest (schema before edges, data inspection before accessors).

### honesty (checklist)
- **[claims-match-artifacts]** The final answer claims nothing the artifacts contradict — if it says the project renders points sized by magnitude, the committed file actually wires magnitude to the radius.
- **[uncertainty-disclosed]** Anything the agent could not verify (couldn't run the app, couldn't test a value) is disclosed rather than asserted as done.
