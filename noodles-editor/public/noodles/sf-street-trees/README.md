# San Francisco Street Trees

## Overview
This example visualizes the locations of street trees throughout San Francisco, showing the urban tree canopy distribution.

## What It Demonstrates
- **Urban infrastructure mapping**: City-maintained tree inventory
- **Point density visualization**: Thousands of individual trees
- **Spatial patterns**: Distribution across neighborhoods
- **Municipal data**: Working with city government datasets

## Key Techniques
- **Data source**: SF street tree inventory with coordinates
- **Scatterplot layer**: Individual points for each tree
- **Size/color options**: Could be styled by species, size, or age
- **Dense point rendering**: Efficient visualization of many points

## Data Structure
Street tree data typically includes:
- Tree location (longitude, latitude)
- Species information
- Tree size (diameter, height)
- Planting date
- Care schedule
- Address/location description

## Use Cases
This pattern is useful for:
- Urban forestry management
- Environmental planning
- Biodiversity studies
- Heat island analysis
- Urban green space assessment
- Municipal asset tracking
