# Plane roll

A 22-second fictional sightseeing flight over Lake Zurich. A chase camera follows
the aircraft while its roll track banks from level to +28°, through level to −32°,
then back to level. The route, cyan trail, and aircraft share the rolled map view;
the instrument panel uses a separate orthographic view and stays upright.

Open `/examples/plane-roll` in the editor (locally,
<http://localhost:5173/examples/plane-roll>). The project contains eight nodes and
uses native timeline keyframes on `/camera.roll`. `/flight` calculates position
and heading; `/aircraft` uses the same roll value for the model's bank.
Its orientation includes a 90° axis correction for this glTF asset; the camera
bank consequently drives the first component of the model orientation.

## Try it and export

1. Play the timeline. The bank readout and map should change together, while the
   aircraft stays on the cyan trail and the instrument panel remains level.
2. Scrub to 6 seconds (+28°), 10 seconds (0°), and 14 seconds (−32°). Check that
   the map and deck.gl layers remain aligned at each angle.
3. To edit the bank, show the node graph, select `/camera`, and edit its `roll`
   keyframes in the timeline. A value of zero restores the ordinary map camera.
4. Choose **Menu → Start Render** and save the MP4. `/out` is configured for
   1280 × 720, 30 fps, 12 Mbps, and a 22-second sequence. The export contains the
   visualization and instrument panel. Chrome supports the video capture APIs
   used by this renderer.

Roll currently supports Mercator maps and standalone MapViews. Noodles supplies
a local viewport adapter because deck.gl 9.4's MapView and MapLibreOverlay do not
yet synchronize roll. No upstream deck.gl patch is required to run this example.
The replacement for this adapter is tracked in
[deck.gl's camera roll PR](https://github.com/visgl/deck.gl/pull/10697).

## Assets

- Aircraft: [deck.gl-data scenegraph example](https://github.com/visgl/deck.gl-data/blob/master/examples/scenegraph-layer/airplane.glb),
  stored locally as `public/plane-roll.glb`, with its MIT license in
  `public/plane-roll.LICENSE.txt`.
- Basemap: [CARTO Dark Matter](https://carto.com/basemaps/), using OpenStreetMap
  data. The style and tiles require an internet connection; no API key is needed.
- Flight path and instrument display are generated by this project. They do not
  represent a real flight or real flight telemetry.
